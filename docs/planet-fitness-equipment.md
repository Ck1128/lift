# Planet Fitness equipment defaults

Version `presets-2`, reviewed 2026-10-21 (constants `PRESET_VERSION`, `PRESET_REVIEWED` in `src/engine/equipment.ts`).

Source: the general public description of a typical Planet Fitness club (selectorized machines, cable stations, Smith machines, dumbbells, cardio machines; no barbells or squat racks). Clubs differ, so this is a starting point, not a guarantee.

Default available: bodyweight, mat, dumbbells, machines, cables, Smith machine, bench, treadmill, exercise bike, elliptical, stair climber.
Default not available: barbell and plates, pull-up bar, kettlebells, bands, rower.

You can exclude anything missing at your club. Exclusions are stored with the preset, so a future list update does not erase them. Editing the list by hand converts it to a custom list. Review the list at least once a year.
